Today we're publishing the first version of the PanjatanTech developer portal. It covers everything you need to make your first request and to build with each of our four products.

## Six guides

- **[Quickstart](/developers/docs/quickstart):** create a key, install the SDK, list models and run your first inference.
- **[Authentication](/developers/docs/authentication):** how API keys work and how to keep them safe.
- **[Inference API](/developers/docs/inference-api):** request and response shapes, token usage and streaming.
- **[Vector Store](/developers/docs/vector-store):** add documents, query an index and use the results for RAG.
- **[Agents](/developers/docs/agents):** start durable agent runs and retrieve their output.
- **[Evaluation](/developers/docs/evaluation):** score a model or prompt against a test set, including in CI.

Every example is shown in TypeScript, cURL and Python, with a copy button on each.

## Try it without a key

The [API explorer](/developers/api) lists every endpoint. Pick one, fill in the parameters and press **Try it**. Requests from the explorer go to a sandbox that returns sample responses, so you can see the shape of each call before you write any code. The explorer also generates the matching code for you to copy.

## SDKs

The TypeScript SDK is documented on the [SDKs page](/developers/sdks). Python and Go SDKs are in development; until they ship, every guide includes a Python example using plain HTTP.
