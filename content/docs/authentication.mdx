Requests are authenticated with a bearer token in the `Authorization` header.

## Bearer tokens

```ts
const res = await fetch("https://api.example.com/v1/models", {
  headers: { Authorization: `Bearer ${process.env.PANJATAN_API_KEY}` },
});
```

## Keeping keys safe

- Never ship keys in client-side code.
- Use separate keys per environment.
- Rotate keys if you suspect exposure.
