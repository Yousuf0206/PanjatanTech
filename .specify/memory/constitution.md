# PanjatanTech Website Constitution

**Version:** 1.0 · **Ratified:** 2026-10-14

These are non-negotiable principles. Every design, technical, and product decision must pass through this filter.

## Core Principles

### I. Technical Excellence First
The website must reflect the same engineering standards as our AI products. No visual or functional shortcuts are acceptable.

### II. Developer Experience is Sacred
Every interaction for developers (documentation, API explorer, playgrounds, SDKs) must be fast, clear, and delightful.

### III. Trust Through Transparency
Pricing, security claims, uptime numbers, and product capabilities must be accurate and verifiable. No unsupported marketing claims.

### IV. Performance is a Feature
- Largest Contentful Paint < 1.2s
- Total Blocking Time < 150ms
- Cumulative Layout Shift < 0.05

### V. Accessibility is Non-Negotiable
WCAG 2.2 AA minimum. Full keyboard navigation, screen-reader support, proper contrast, and respect for `prefers-reduced-motion`.

### VI. Security & Privacy by Design
Strict Content Security Policy. No unnecessary third-party tracking. Developer portal must support SSO and MFA.

### VII. Brand Consistency
Colors: Deep Navy `#0B1120`, Electric Cyan `#00E5FF`, Soft Purple `#A78BFA`, Pure White `#FFFFFF`.
Logo and visual language must remain consistent across all surfaces.

### VIII. Conversion Without Compromise
Strong calls-to-action are required, but never at the cost of clarity or user trust.

### IX. Mobile-First, Desktop-Optimized
Design and development start at 375px and scale cleanly to 1920px+.

### X. Maintainability Over Cleverness
Prefer simple, well-documented, and testable solutions.

## Decision Rule
Any proposal that violates one or more of the above principles is rejected by default.
